# RetailIQ — Evidence-First Sales & Inventory Copilot

RetailIQ is an evidence-first AI copilot for retail sales analytics and inventory intelligence.

## Getting Started

### Prerequisites
- Python 3.11+

### Installation & Run Instructions

```bash
pip install -r requirements.txt
python app.py
```

The application runs on [http://localhost:8000](http://localhost:8000).

### Available Endpoints
- `GET /` — Root status confirmation
- `GET /health` — Service health check
